# PR #1071 review findings

Audited on 2026-11-26 against [`dc12968b`](https://github.com/nethesis/ns8-nethvoice/commit/dc12968b41ac6f59fb5fd7c19f8fd32e13389452). GitHub reported a merge conflict with `main`. The public English and Italian help pages both returned HTTP 404.

**Working document. Remove before merging this PR.**

The main release blockers are **GPT-Live mid-call drops** and **the private greeting timeout**. See R1 for the testing-image build. The original infrastructure changes and SIP codec fix have supporting evidence. Some UI fixes passed an earlier retest and regressed in the integration merge.

**Status** — Addressed means the requested change is present. Partial means a material part is still missing. Open means the issue persists or the requested change is absent. Deferred marks an explicit follow-up. Baseline marks measurements or positive checks that did not request a fix. Where evidence is limited to source, tests, or an earlier lab head, the row says so.

Paths are relative to `ns8-nethvoice`. `Agents UI` refers to `freepbx/agents-ui/src`; `Agents PHP` refers to `freepbx/var/www/html/freepbx/rest/lib/agents`.
